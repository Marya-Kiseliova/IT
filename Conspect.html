ОСНОВЫ HTML

Базовая структура документа

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Название страницы</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- Содержимое страницы -->
</body>
</html>

Основные HTML-теги

Тег Назначение Пример
<div> Универсальный контейнер <div class="container">...</div>
<h1>-<h6> Заголовки разного уровня <h1>Главный заголовок</h1>

СЕМАНТИЧЕСКИЕ ТЕГИ

Структурные семантические теги

Тег Назначение Пример
<header> Шапка сайта или раздела <header>Логотип и навигация</header>
<nav> Навигационное меню <nav><a href="#">Главная</a></nav>
<main> Основное содержимое <main>Основной контент...</main>
<section> Тематический раздел <section><h2>О нас</h2>...</section>
<article> Самостоятельный контент <article><h2>Статья</h2>...</article>
<footer> Подвал сайта или раздела <footer>Контакты и ссылки</footer>

DIV vs SECTION vs ARTICLE

<div> - Универсальный контейнер Используется для группировки элементов без семантического значения.
<div class="user-card">
  <img src="avatar.jpg" alt="Аватар">
  <h3>Имя пользователя</h3>
</div>
<section> - Тематический раздел Для логического разделения контента. Должен иметь заголовок.
<section class="services">
  <h2>Наши услуги</h2>
  <div class="service-card">...</div>
</section>
<article> - Независимый контент Для самостоятельного контента (статьи, посты, карточки товаров).
<article class="blog-post">
  <h2>Заголовок поста</h2>
  <p>Содержание...</p>
</article>

ОТСТУПЫ: MARGIN, PADDING, GAP

Визуализация отступов

MARGIN BORDER PADDING Контент элемента

MARGIN

Внешние отступы - пространство ВНЕ элемента

.element {
  margin: 20px; /* со всех сторон */
  margin: 10px 20px; /* верх-низ | лево-право */
}
  • Margin'ы соседних элементов схлопываются
  • Можно использовать отрицательные значения
  • auto для центрирования

PADDING

Внутренние отступы - пространство ВНУТРИ элемента

.element {
  padding: 20px; /* со всех сторон */
  padding: 10px 20px 15px 5px;
}
  • Увеличивает размер элемента
  • Нельзя использовать отрицательные значения
  • Влияет на кликабельную область

GAP - современный способ

gap Отступы между элементами в Flexbox и Grid.
.container {
  display: grid;
  gap: 20px; /* отступы между элементами */
  padding: 30px; /* отступ от краев */
}

БУРГЕР-МЕНЮ

Что такое бургер-меню?

Бургер-меню — это иконка из трёх горизонтальных линий, которая открывает навигационное меню на мобильных устройствах.

HTML структура

<!-- Кнопка бургер-меню -->
<button class="burger-menu" aria-label="Открыть меню">
  <div class="burger-line"></div>
  <div class="burger-line"></div>
  <div class="burger-line"></div>
</button>

Правильно

  • Используйте семантические теги button
  • Добавляйте aria-label для доступности
  • Создавайте плавные анимации
  • Закрывайте меню при клике на пункт

Неправильно

  • Использовать div вместо button
  • Забывать про закрывающую кнопку
  • Создавать резкие анимации
  • Игнорировать мобильную оптимизацию

LAYOUTS И МАКЕТЫ

Что такое Layout?

Layout (макет, вёрстка) — это структурная организация элементов на веб-странице.

Проще говоря: макет — это архитектурный план вашего сайта.

FLEXBOX

Для одномерных макетов - размещение элементов в одну строку или один столбец.

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

CSS GRID

Для двумерных макетов - одновременное управление строками и столбцами.

.container {
  display: grid;
  grid-template-columns: 1fr 300px;
  gap: 20px;
}

Mobile-First подход

/* Стили для мобильных устройств (базовые) */
.container {
  padding: 15px;
  display: block;
}

/* Планшеты */
@media (min-width: 768px) {
  .container {
    display: grid;
    grid-template-columns: 1fr 1fr;
  }
}
